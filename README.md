## Dataset

Source: [Materials Project](https://next-gen.materialsproject.org/) — electronic structure / density-of-states API endpoint (`mp-api` client).

- Citation: A. Jain et al., "Commentary: The Materials Project: A materials genome approach to accelerating materials innovation," *APL Materials* 1, 011002 (2013). https://doi.org/10.1063/1.4812323
- Access: free API key required. Register at https://next-gen.materialsproject.org/api to obtain one.
- Query filters: `theoretical=False` (experimentally observed, ICSD-matched compounds) and `band_gap == 0` (metals, where DOS(E_F) is physically meaningful).

## Running the notebooks

Run in order, top to bottom (Kernel → Restart & Run All), from inside `notebooks/`:

**01 → 02 → 03 → 04**

1. **`01_data_acquisition.ipynb`** — Materials Project query (`theoretical=False`, `band_gap == 0`), deduplication by composition, elemental family/period labeling, stratified sampling, DOS(E_F) extraction. Writes `data/metals_dos.csv`.
2. **`02_eda_featurization.ipynb`** — exploratory data analysis (family/crystal-system counts, DOS(E_F) distribution), then MAGPIE compositional featurization + one-hot crystal system. Writes `data/features.csv`.
3. **`03_modeling.ipynb`** — Random Forest baseline vs. `GroupKFold` cross-validation (by family and by period), held-out 80/20 train/test split, Lasso feature selection. Writes `data/cv_results.csv`, `data/predictions.csv`, `data/lasso_coefficients.csv`.
4. **`04_results_visualization.ipynb`** — loads the CSVs from notebook 03 (and `features.csv` from 02) and produces all four report figures, saved to `figures/`.

Raw Materials Project query results (including full `Structure` objects) are cached to `cache/metals_query_cache.pkl` after the first run of notebook 01, so re-running doesn't re-hit the API. This cache file is ~72 MB, so `cache/` is excluded from the repo via `.gitignore` — it regenerates automatically the first time notebook 01 runs (requires a valid `MP_API_KEY` and internet access) and is not needed to clone or set up the project. Delete it to force a fresh query (e.g. after changing filter criteria). See `data/README.md` for what each generated data file contains.

> **Note:** these notebooks were not executed in the authoring environment (no network access to the Materials Project API there). Run them locally or on a machine with internet access and a valid API key.
